# Upstream D specification review sources

The Ddoc files in this directory are retained as non-normative upstream review
material for Laser-D.

They provide feature-discovery coverage and traceability to the D language from
which Laser-D is derived. They do not define Laser-D behavior. The sole
normative Laser-D language specification is the Markdown specification under
[`spec-markdown/`](../spec-markdown/README.md).

For each reviewed feature, `FEATURE_STATUS.md` distinguishes:

- the normative Laser-D specification;
- the upstream review source in this directory; and
- the Laser-D tests that provide executable evidence.

Unreviewed or undocumented behavior found in these files is not an accidental
Laser-D guarantee.
